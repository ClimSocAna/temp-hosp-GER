Code for replicating the analysis of the paper "Regional heterogeneity in the association between extreme temperatures and emergency hospitalizations in Germany"

In this paper, we investigate how regional characteristics modify the relationship between temperature and emergency hospitalizations in Germany through fixed effects models by interacting regional socioeconomic deprivation with the weekly number of days falling into one of eleven temperature bins, adjusting for seasonality. Analysis was stratified by degree of urbanization and age group. 

This study uses restricted data from the G-DRG Statistic (https://doi.org/10.21242/23141.2005.00.00.1.1.0 to 10.21242/23141.2021.00.00.1.1.0) through remote execution. Remote execution restricts users to submitting code for execution on the RDC's servers and only aggregated results, subject to statistical disclosure control, are returned to the researcher. Data access can be applied for through the Research Data Center (RDC) of the Federal Statistical Office and Offices (see https://www.forschungsdatenzentrum.de/en/request). All other data sources used in this study are publicly available. Population counts can be obtained from https://www.destatis.de/EN, temperature information is available at https://cds.climate.copernicus.eu, the German Index of Socioeconomic Deprivation can be found on https://robert-koch-institut.github.io/German_Index_of_Socioeconomic_Deprivation_GISD/ and regional characteristics were obtained from https://www.inkar.de/. 

We provide toy data that can be used to run the analysis scripts (excluding data_preprocessing.R). The test dataset does not resemble the distributions of the original dataset that was used for the analysis of our paper. The processed data for climate and regional characteristics (not the data from the G-DRG Statistic) can be provided from the corresponding author upon request.
